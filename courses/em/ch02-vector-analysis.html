核心觀念 Key Ideas

內積與外積 Dot and cross products

內積（dot product）在問「$\mathbf{A}$ 有多少落在 $\mathbf{B}$ 的方向上」，結果是純量：$\mathbf{A}\cdot\mathbf{B} = AB\cos\theta_{AB}$。兩向量垂直時內積為零，這是判斷垂直最快的方法。

外積（cross product）的結果是向量，大小是兩向量張出的平行四邊形面積 $AB\sin\theta_{AB}$，方向用右手定則決定，並且垂直於兩者。外積不滿足交換律：$\mathbf{B}\times\mathbf{A} = -\mathbf{A}\times\mathbf{B}$。

正交座標系 Orthogonal coordinate systems

三種座標系都是「三個互相垂直的單位向量」，差別在於圓柱和球座標的單位向量方向會隨位置改變。例如 $\mathbf{a}_r$ 在 $\phi = 0$ 指向 $x$ 軸、在 $\phi = \pi/2$ 指向 $y$ 軸。

度量係數（metric coefficient）$h_1, h_2, h_3$ 把「座標變化量」換成「真的長度」：圓柱座標裡 $\phi$ 改變 $d\phi$，實際走的弧長是 $r\,d\phi$，所以 $h_2 = r$。散度、旋度公式裡那些 $1/r$、$\sin\theta$ 全部來自度量係數。

梯度 Gradient

梯度作用在純量場上，得到一個向量：方向是純量增加最快的方向，大小是那個方向上的增加率。它一定垂直於等值面（例如等位面）。

想知道沿任意方向 $\mathbf{a}_\ell$ 的變化率，只要做內積：$dV/d\ell = \nabla V\cdot\mathbf{a}_\ell$，這叫方向導數（directional derivative）。

散度與散度定理 Divergence and the divergence theorem

散度在量「一個點像不像源頭」：取一個很小的封閉曲面包住那個點，算淨流出量再除以體積。結果為正代表有東西往外冒（源），為負代表被吸進去（匯），為零代表進出相等。

$$\nabla\cdot\mathbf{A} = \lim_{\Delta v\to 0}\frac{\oint_S \mathbf{A}\cdot d\mathbf{s}}{\Delta v}$$

把很多小體積加起來，內部相鄰的面通量互相抵消，只剩最外層，就得到散度定理：體積內散度的總和 = 穿出邊界的總通量。

旋度與 Stokes 定理 Curl and Stokes's theorem

旋度在量「一個點附近的場有沒有在打轉」：在小面積的邊界繞一圈算環量（circulation），除以面積，取讓結果最大的那個面方向，就是旋度的方向。想像在水流裡放一個小風車，風車轉得越快、旋度越大，轉軸就是旋度方向。

同樣把很多小面積拼起來，內部的邊互相抵消，得到 Stokes 定理：曲面上旋度的通量 = 沿邊界的環量。邊界繞行方向和曲面法向量要符合右手定則。

零恆等式與 Helmholtz 定理 Null identities and Helmholtz's theorem

兩個零恆等式：梯度場沒有旋度 $\nabla\times(\nabla V) = 0$；旋度場沒有散度 $\nabla\cdot(\nabla\times\mathbf{A}) = 0$。反過來說：無旋場（irrotational）一定可以寫成某純量的梯度，無源場（solenoidal）一定可以寫成某向量的旋度。

Helmholtz 定理說：一個在無窮遠處趨近於零的向量場，只要知道它的散度和旋度，就被唯一決定。所以後面學電磁學時，每種場都只要記「它的散度是什麼、旋度是什麼」。

例題 Worked Examples

例題 1　內積、外積與夾角

Given $\mathbf{A} = \mathbf{a}_x2 - \mathbf{a}_y3 + \mathbf{a}_z$ and $\mathbf{B} = \mathbf{a}_x + \mathbf{a}_y4 - \mathbf{a}_z2$, find (a) $\mathbf{A}\cdot\mathbf{B}$, (b) the angle between $\mathbf{A}$ and $\mathbf{B}$, and (c) $\mathbf{A}\times\mathbf{B}$.

提示：夾角用內積公式反推；外積算完用 $\mathbf{A}\cdot(\mathbf{A}\times\mathbf{B}) = 0$ 檢查。

看詳解
  1. $\mathbf{A}\cdot\mathbf{B} = (2)(1) + (-3)(4) + (1)(-2) = 2 - 12 - 2 = -12$。
  2. $A = \sqrt{4+9+1} = \sqrt{14}$，$B = \sqrt{1+16+4} = \sqrt{21}$。
  3. $\cos\theta_{AB} = \dfrac{-12}{\sqrt{14}\sqrt{21}} = -0.700$，所以 $\theta_{AB} = 134.4^\circ$（內積為負，夾角大於 $90^\circ$）。
  4. 外積：$\mathbf{a}_x[(-3)(-2) - (1)(4)] - \mathbf{a}_y[(2)(-2) - (1)(1)] + \mathbf{a}_z[(2)(4) - (-3)(1)] = \mathbf{a}_x2 + \mathbf{a}_y5 + \mathbf{a}_z11$。
  5. 檢查：$\mathbf{A}\cdot(\mathbf{A}\times\mathbf{B}) = 4 - 15 + 11 = 0$，確實垂直。

答：(a) $-12$　(b) $134.4^\circ$　(c) $\mathbf{a}_x2 + \mathbf{a}_y5 + \mathbf{a}_z11$

例題 2　梯度與方向導數

For the scalar field $V = x^2y + 2yz$, find (a) $\nabla V$ at $P(1, 2, -1)$, (b) the rate of change of $V$ at $P$ in the direction of $\mathbf{a}_x2 + \mathbf{a}_y + \mathbf{a}_z2$, and (c) the maximum rate of change of $V$ at $P$.

提示：方向一定要先換成單位向量。最大變化率就是梯度的大小。

看詳解
  1. $\nabla V = \mathbf{a}_x(2xy) + \mathbf{a}_y(x^2 + 2z) + \mathbf{a}_z(2y)$。
  2. 代入 $P(1,2,-1)$：$\nabla V = \mathbf{a}_x4 + \mathbf{a}_y(1-2) + \mathbf{a}_z4 = \mathbf{a}_x4 - \mathbf{a}_y + \mathbf{a}_z4$。
  3. 方向的大小是 $\sqrt{4+1+4} = 3$，單位向量 $\mathbf{a}_\ell = (\mathbf{a}_x2 + \mathbf{a}_y + \mathbf{a}_z2)/3$。
  4. $dV/d\ell = \nabla V\cdot\mathbf{a}_\ell = (8 - 1 + 8)/3 = 5$。
  5. 最大變化率 $= |\nabla V| = \sqrt{16 + 1 + 16} = \sqrt{33} \approx 5.74$。

答：(a) $\mathbf{a}_x4 - \mathbf{a}_y + \mathbf{a}_z4$　(b) $5$（每單位長度）　(c) $\sqrt{33}\approx 5.74$

例題 3　驗證散度定理

Given $\mathbf{A} = \mathbf{a}_x x^2 + \mathbf{a}_y xy + \mathbf{a}_z yz$, verify the divergence theorem over the unit cube $0 \le x, y, z \le 1$.

提示：兩邊分開算。面積分有六個面，先想清楚每個面的 $d\mathbf{s}$ 朝哪裡，很多面會直接是零。

看詳解
  1. $\nabla\cdot\mathbf{A} = 2x + x + y = 3x + y$。
  2. 體積分：$\int_0^1\!\int_0^1\!\int_0^1 (3x + y)\,dx\,dy\,dz = \tfrac{3}{2} + \tfrac{1}{2} = 2$。
  3. $x = 1$ 面（$d\mathbf{s} = \mathbf{a}_x\,dy\,dz$）：$A_x = 1$，通量 $= 1$。$x = 0$ 面（$d\mathbf{s} = -\mathbf{a}_x\,dy\,dz$）：$A_x = 0$，通量 $= 0$。
  4. $y = 1$ 面：$A_y = x$，通量 $= \int_0^1\!\int_0^1 x\,dx\,dz = \tfrac12$。$y = 0$ 面：$A_y = 0$。
  5. $z = 1$ 面：$A_z = y$，通量 $= \tfrac12$。$z = 0$ 面：$A_z = 0$。
  6. 總通量 $= 1 + \tfrac12 + \tfrac12 = 2$，與體積分相同。

答：兩邊都等於 $2$，散度定理成立。

例題 4　圓柱座標的 Stokes 定理

Given $\mathbf{A} = \mathbf{a}_\phi\,3r^2$ in cylindrical coordinates, verify Stokes's theorem for the circular disk $r \le 1$ in the $z = 0$ plane, with the contour traversed counterclockwise as seen from $+z$.

提示：逆時針繞行配上 $d\mathbf{s} = \mathbf{a}_z\,r\,dr\,d\phi$。旋度只剩 $z$ 分量。

看詳解
  1. 線積分：在 $r = 1$ 上 $d\boldsymbol{\ell} = \mathbf{a}_\phi\,r\,d\phi = \mathbf{a}_\phi\,d\phi$，$\oint \mathbf{A}\cdot d\boldsymbol{\ell} = \int_0^{2\pi} 3(1)^2\,d\phi = 6\pi$。
  2. 旋度（圓柱，$h = (1, r, 1)$）：只有 $A_\phi$，所以 $\nabla\times\mathbf{A} = \mathbf{a}_z\dfrac{1}{r}\dfrac{\partial (r\cdot 3r^2)}{\partial r} = \mathbf{a}_z\dfrac{9r^2}{r} = \mathbf{a}_z\,9r$。
  3. 面積分：$\int_0^{2\pi}\!\int_0^1 9r\cdot r\,dr\,d\phi = 9\cdot\tfrac13\cdot 2\pi = 6\pi$。

答：兩邊都等於 $6\pi \approx 18.85$，Stokes 定理成立。

常見陷阱 Pitfalls

  • 常見錯法：把 $\mathbf{a}_r$、$\mathbf{a}_\phi$ 當成常數提到積分外面，例如 $\int_0^{2\pi}\mathbf{a}_r\,d\phi = 2\pi\,\mathbf{a}_r$。

    正確想法：圓柱和球座標的單位向量會隨位置轉向，積分前要先換成直角座標：$\mathbf{a}_r = \mathbf{a}_x\cos\phi + \mathbf{a}_y\sin\phi$，繞一圈積分結果是 $0$。

  • 常見錯法：圓柱座標的散度寫成 $\partial A_r/\partial r + \partial A_\phi/\partial\phi + \partial A_z/\partial z$。

    正確想法：非直角座標一定有度量係數：$\frac{1}{r}\frac{\partial(rA_r)}{\partial r} + \frac{1}{r}\frac{\partial A_\phi}{\partial\phi} + \cdots$。考前把三種座標的散度各默寫一次。

  • 常見錯法：散度定理的六個面都用 $+\mathbf{a}_x$、$+\mathbf{a}_y$、$+\mathbf{a}_z$ 當法向量。

    正確想法：$d\mathbf{s}$ 一律朝外，所以 $x = 0$ 那面是 $-\mathbf{a}_x$。只要那個面上的分量不為零，符號就會影響答案。

  • 常見錯法：外積順序寫反，或行列式展開時中間項忘記加負號。

    正確想法：$\mathbf{A}\times\mathbf{B} = -\mathbf{B}\times\mathbf{A}$。算完用「和兩個原向量內積都是零」檢查一次，三秒就能抓到錯。

  • 常見錯法：對純量取散度，或對散度（純量）再取旋度。

    正確想法：梯度：純量進、向量出；散度：向量進、純量出；旋度：向量進、向量出。寫算式前先確認每一層的型別。

自我檢測 Self-check

1. 在圓柱座標中，$\int_0^{2\pi}\mathbf{a}_r\,d\phi$ 等於？

$\mathbf{a}_r = \mathbf{a}_x\cos\phi + \mathbf{a}_y\sin\phi$，$\cos\phi$ 和 $\sin\phi$ 繞一圈積分都是 $0$。選 A 就是把單位向量當成常數了。

2. 某向量場在空間中處處 $\nabla\cdot\mathbf{A} = 0$，可以推出什麼？

由散度定理，$\oint_S\mathbf{A}\cdot d\mathbf{s} = \int_V 0\,dv = 0$。D 說的是無旋場（$\nabla\times\mathbf{A} = 0$）的性質，不是無源場。

3. 下列哪一個運算沒有意義？

$\nabla\cdot\mathbf{A}$ 是純量，純量不能取旋度。B 是 Laplacian，C 是散度的梯度，D 恆等於零但有意義。

4. 純量場的梯度和它的等值面是什麼關係？

沿著等值面移動時 $V$ 不變，$\nabla V\cdot d\boldsymbol{\ell} = 0$，所以梯度垂直於等值面。這也是之後「電場垂直於等位面」的原因。

5. 依 Helmholtz 定理，要唯一決定一個在無窮遠處趨近於零的向量場，需要知道什麼？

散度和旋度缺一不可。所以 Maxwell 方程式剛好就是電場、磁場各自的散度和旋度。
