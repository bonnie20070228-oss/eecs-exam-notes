二階電路 Second-Order Circuits

電路裡同時有電感和電容時，能量會在兩者之間來回交換，響應可能直接衰減，也可能邊振盪邊衰減。決定是哪一種的，只有 $\alpha$ 和 $\omega_0$ 兩個數字。

本章地圖 Overview

第 7 章的一階電路只有一個儲能元件，答案永遠是一個指數。這章多了一個儲能元件，微分方程變成二階，所以要兩個初始條件、兩個待定常數。解題流程每一題都一樣：求初值與終值，算 $\alpha$、$\omega_0$ 判斷阻尼型態，寫出對應的響應形式，最後用初始條件解常數。下一章開始的弦波穩態分析，則是只看「穩態」那一半。

核心觀念 Key Ideas

初值與終值 Initial and final values

換路瞬間只有兩個量不會跳：電容電壓 $v_C$ 和電感電流 $i_L$，因為它們代表儲存的能量，能量不能在一瞬間改變。其他量（電容電流、電感電壓、電阻上的量）都可能跳。

二階電路還需要一階導數的初值。技巧是把導數換成「看得到的量」：$dv_C/dt = i_C/C$、$di_L/dt = v_L/L$，所以先在 $t = 0^+$ 用 KCL、KVL 求出 $i_C(0^+)$ 和 $v_L(0^+)$。終值則是直流穩態：電容開路、電感短路。

特徵方程式 Characteristic equation

不論串聯或並聯，二階電路的方程式都整理成同一個樣子：$\dfrac{d^2x}{dt^2} + 2\alpha\dfrac{dx}{dt} + \omega_0^2 x = 0$。代入 $x = Ae^{st}$ 得到 $s^2 + 2\alpha s + \omega_0^2 = 0$，兩個根就決定了響應的長相。

$\alpha$ 是衰減的快慢（電阻消耗能量），$\omega_0$ 是 L 和 C 交換能量的自然頻率。兩種接法的 $\omega_0$ 都是 $1/\sqrt{LC}$，只有 $\alpha$ 的公式不同。

三種阻尼 Overdamped, critically damped, underdamped

比較 $\alpha$ 和 $\omega_0$：$\alpha > \omega_0$ 時兩根是相異實數，電阻消耗太快、來不及振盪，叫過阻尼；$\alpha = \omega_0$ 是重根，叫臨界阻尼，是「不振盪中最快回到零」的情況；$\alpha < \omega_0$ 時兩根是共軛複數，會振盪，叫欠阻尼。

欠阻尼的振盪頻率不是 $\omega_0$，而是比較小的阻尼自然頻率 $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$，振幅則以 $e^{-\alpha t}$ 衰減。

步級響應 Step response

加上直流電源後，完全響應 = 穩態響應 + 暫態響應。穩態就是終值 $x(\infty)$；暫態的形式和零輸入響應完全一樣，只是常數要重新解。

最常見的錯誤是解常數時漏掉穩態項：初始條件是套在「完全響應」上，$x(0) = x(\infty) + (\text{暫態在 } t=0 \text{ 的值})$。

例題 Worked Examples

例題 1　串聯 RLC 零輸入，過阻尼

A source-free series RLC circuit has $R = 6\,\Omega$, $L = 1\,\text{H}$ and $C = 0.2\,\text{F}$. Let $i(t)$ be the loop current entering the positive terminal of the capacitor. At $t = 0$, the capacitor voltage is $v(0) = 10\,\text{V}$ and $i(0) = 0$. (a) Determine $\alpha$, $\omega_0$ and the type of damping. (b) Find $i(t)$ for $t > 0$. (c) When does $|i(t)|$ reach its maximum, and what is that value?

提示：$t = 0^+$ 時 KVL：$L\,di/dt = -Ri - v$，用它求 $di(0^+)/dt$。

看詳解
  1. $\alpha = R/2L = 6/2 = 3\,\text{s}^{-1}$，$\omega_0 = 1/\sqrt{LC} = 1/\sqrt{0.2} = \sqrt5 \approx 2.24\,\text{rad/s}$。$\alpha > \omega_0$，過阻尼。
  2. $s_{1,2} = -3 \pm \sqrt{9 - 5} = -3 \pm 2$，得 $s_1 = -1$、$s_2 = -5$。所以 $i(t) = A_1e^{-t} + A_2e^{-5t}$。
  3. $i(0) = 0 \Rightarrow A_1 + A_2 = 0$。
  4. $di(0^+)/dt = -(Ri(0) + v(0))/L = -(0 + 10)/1 = -10\,\text{A/s}$，所以 $-A_1 - 5A_2 = -10$。
  5. 代入 $A_2 = -A_1$：$4A_1 = -10$，$A_1 = -2.5$、$A_2 = 2.5$。
  6. $i(t) = 2.5\left(e^{-5t} - e^{-t}\right)\,\text{A}$。負號代表電流實際是電容放電的方向。
  7. 極值：$di/dt = 2.5(-5e^{-5t} + e^{-t}) = 0 \Rightarrow e^{4t} = 5$，$t = \tfrac{\ln 5}{4} \approx 0.402\,\text{s}$。代回得 $i \approx -1.34\,\text{A}$。

答：(a) $\alpha = 3\,\text{s}^{-1}$、$\omega_0 = \sqrt5\,\text{rad/s}$，過阻尼　(b) $i(t) = 2.5(e^{-5t} - e^{-t})\,\text{A}$　(c) $t \approx 0.402\,\text{s}$ 時 $|i| \approx 1.34\,\text{A}$

例題 2　並聯 RLC 零輸入，臨界阻尼

In a source-free parallel RLC circuit, $R = 1\,\Omega$, $L = 1\,\text{H}$ and $C = 0.25\,\text{F}$. The capacitor voltage is $v(0) = 5\,\text{V}$ and the inductor current is $i_L(0) = 0$ ($i_L$ flows from the top node through $L$). Find $v(t)$ for $t > 0$, the time at which $v(t)$ first crosses zero, and the minimum value of $v(t)$.

提示：並聯時 $t = 0^+$ 的 KCL：$C\,dv/dt = -v/R - i_L$。

看詳解
  1. $\alpha = 1/2RC = 1/(2\cdot 1\cdot 0.25) = 2\,\text{s}^{-1}$，$\omega_0 = 1/\sqrt{0.25} = 2\,\text{rad/s}$。$\alpha = \omega_0$，臨界阻尼。
  2. $v(t) = (A_1 + A_2t)e^{-2t}$，$v(0) = A_1 = 5$。
  3. $dv(0^+)/dt = -(v(0)/R + i_L(0))/C = -(5 + 0)/0.25 = -20\,\text{V/s}$。
  4. $dv/dt = (A_2 - 2A_1 - 2A_2t)e^{-2t}$，在 $t = 0$：$A_2 - 2A_1 = -20$，$A_2 = -10$。
  5. $v(t) = (5 - 10t)e^{-2t}\,\text{V}$，在 $t = 0.5\,\text{s}$ 變號。
  6. 極小值：$dv/dt = (-20 + 20t)e^{-2t} = 0 \Rightarrow t = 1\,\text{s}$，$v(1) = -5e^{-2} \approx -0.677\,\text{V}$。

答：$v(t) = (5 - 10t)e^{-2t}\,\text{V}$；$t = 0.5\,\text{s}$ 過零；最小值 $-0.677\,\text{V}$（$t = 1\,\text{s}$）

例題 3　串聯 RLC 步級響應，欠阻尼

A $12\,\text{V}$ DC source is switched on at $t = 0$ into a series RLC circuit with $R = 2\,\Omega$, $L = 1\,\text{H}$ and $C = 0.2\,\text{F}$. The circuit is initially at rest. Find (a) the capacitor voltage $v(t)$, (b) the current $i(t)$, and (c) the peak value of $v(t)$.

提示：終值 $v(\infty) = 12\,\text{V}$（電容開路）。$dv(0^+)/dt = i(0^+)/C$。

看詳解
  1. $\alpha = 2/2 = 1\,\text{s}^{-1}$，$\omega_0 = \sqrt5\,\text{rad/s}$，欠阻尼，$\omega_d = \sqrt{5 - 1} = 2\,\text{rad/s}$。
  2. $v(t) = 12 + e^{-t}(B_1\cos 2t + B_2\sin 2t)$。
  3. $v(0) = 0$：$12 + B_1 = 0$，$B_1 = -12$。
  4. $i(0) = 0$，所以 $dv(0^+)/dt = 0$：$-B_1 + 2B_2 = 0$，$B_2 = -6$。
  5. $v(t) = 12 - e^{-t}(12\cos 2t + 6\sin 2t)\,\text{V}$。
  6. $i = C\,dv/dt$。微分整理後 $dv/dt = 30e^{-t}\sin 2t$，所以 $i(t) = 0.2\cdot 30\,e^{-t}\sin 2t = 6e^{-t}\sin 2t\,\text{A}$。
  7. $v$ 的峰值出現在 $i = 0$ 的第一個正時刻：$2t = \pi$，$t = \pi/2$。$v(\pi/2) = 12 + 12e^{-\pi/2} \approx 14.49\,\text{V}$，超越量約 $20.8\%$。

答：(a) $v(t) = 12 - e^{-t}(12\cos 2t + 6\sin 2t)\,\text{V}$　(b) $i(t) = 6e^{-t}\sin 2t\,\text{A}$　(c) $14.49\,\text{V}$（$t \approx 1.57\,\text{s}$）

例題 4　由阻尼要求決定 R

A series RLC circuit has $L = 0.5\,\text{H}$ and $C = 2\,\text{mF}$. (a) Find the value of $R$ that makes the circuit critically damped. (b) If $R$ is reduced to half of that value, determine $\alpha$ and the damped natural frequency $\omega_d$.

提示：臨界阻尼就是 $\alpha = \omega_0$，再把 $\alpha = R/2L$ 反解 $R$。

看詳解
  1. $\omega_0 = 1/\sqrt{0.5 \times 0.002} = 1/\sqrt{0.001} \approx 31.62\,\text{rad/s}$。
  2. 臨界阻尼：$R/2L = \omega_0$，$R = 2L\omega_0 = 2(0.5)(31.62) \approx 31.6\,\Omega$。
  3. $R$ 減半為 $15.8\,\Omega$：$\alpha = 15.8/(2\times 0.5) \approx 15.81\,\text{s}^{-1}$，小於 $\omega_0$，變成欠阻尼。
  4. $\omega_d = \sqrt{1000 - 250} = \sqrt{750} \approx 27.39\,\text{rad/s}$。

答：(a) $R \approx 31.6\,\Omega$　(b) $\alpha \approx 15.8\,\text{s}^{-1}$，$\omega_d \approx 27.4\,\text{rad/s}$

常見陷阱 Pitfalls

  • 常見錯法：步級響應解常數時，用 $x_{\text{t}}(0) = x(0)$。

    正確想法：初始條件屬於完全響應：$x(0) = x(\infty) + x_{\text{t}}(0)$。例題 3 就是因為這樣才得到 $B_1 = -12$ 而不是 $0$。

  • 常見錯法：並聯 RLC 也用 $\alpha = R/2L$，或以為 R 變大一定更阻尼。

    正確想法：並聯是 $\alpha = 1/2RC$。並聯時 R 越大，流過電阻的電流越小、消耗越少，反而越容易振盪。

  • 常見錯法：以為換路瞬間電容電流、電感電壓也連續。

    正確想法：只有 $v_C$ 和 $i_L$ 連續。$i_C(0^+)$、$v_L(0^+)$ 要在 $t = 0^+$ 的電路上重新用 KCL、KVL 求。

  • 常見錯法：欠阻尼響應寫成 $e^{-\alpha t}\cos\omega_0 t$。

    正確想法：振盪頻率是 $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$。只有 $\alpha = 0$（無損 LC）時兩者才相同。

  • 常見錯法：求 $dv/dt(0^+)$ 時用了 $t = 0^-$ 的電路，或忘記電流方向和電壓極性的對應。

    正確想法：先畫出 $t = 0^+$ 的電路，標好 $v_C$ 極性與 $i_C$ 方向（被動符號慣例），再列方程式。題目定義的方向不同，常數的正負號就會不同。

自我檢測 Self-check

1. 並聯 RLC 電路中把 R 調大，會發生什麼事？

並聯 $\alpha = 1/2RC$，R 變大 $\alpha$ 變小。$\omega_0 = 1/\sqrt{LC}$ 和 R 無關。A 是串聯電路的情況。

2. 開關切換的瞬間，下列哪一個量一定連續？

$v_C$ 對應電容儲存的能量 $\tfrac12 Cv_C^2$，不能瞬間改變。另一個連續的量是電感電流 $i_L$。

3. 欠阻尼響應的振盪角頻率是多少？

共軛根 $s = -\alpha \pm j\omega_d$，虛部 $\omega_d = \sqrt{\omega_0^2 - \alpha^2}$ 就是振盪頻率。D 在欠阻尼時根號內是負的。

4. 某二階電路的特徵根為 $s_1 = s_2 = -3$，它屬於哪一種？

重根代表 $\alpha = \omega_0 = 3$，響應形式是 $(A_1 + A_2t)e^{-3t}$。
